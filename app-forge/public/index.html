    របៀបបាន APK ពិត

    AppForge បង្កើត project Android ពេញលេញ។ ការបង្គំ APK ត្រូវការ Java + Android SDK ដែលរត់លើ GitHub Actions (ឥតគិតថ្លៃ)។

    1. បង្កើត repo ថ្មីនៅ github.com (Public ឬ Private)។
    2. Upload ឯកសារទាំងអស់ក្នុង ZIP ទៅ root របស់ repo — ត្រូវឃើញ settings.gradle.kts និងថត .github/។
    3. ចូល Actions → Build APK → រង់ចាំ ~២–៤ នាទី។
    4. ចុច run ពណ៌បៃតង → Artifacts → ទាញយក *-apk.zip → ពន្លាតបាន app-debug.apk។
    5. ផ្ញើ APK ទៅទូរស័ព្ទ → ដំឡើង (បើក “Install unknown apps”)។

    សំណួរញឹកញាប់

    ហេតុអ្វីមិនបង្កើត APK នៅទីនេះផ្ទាល់? ការបង្គំ APK ត្រូវការ Android SDK + Gradle + JDK (~១GB) ដែល website ស្ថិតលើ Cloudflare Worker មិនអាចរត់បាន។ GitHub Actions ធ្វើការនេះជំនួស ហើយឥតគិតថ្លៃសម្រាប់ repo ធម្មតា។

    ដាក់លើ Play Store បានទេ? APK នេះជា debug។ ដាក់លើ Play Store ត្រូវការ release keystore + ឯកសារ AAB (អាចបន្ថែមក្រោយ)។
